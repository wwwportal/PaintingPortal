# PaintingPortal

A PHP/MySQL e-commerce web app for browsing and purchasing paintings, built on a Bootstrap front end.

- `genre.php` — browse paintings by genre
- `login.php` / `logout.php` — user authentication
- `my-cart.php` / `payment-method.php` — shopping cart and checkout
- `order-history.php` — past orders
- `includes/` — shared header, menu, and footer layout, plus the DB connection (`config.php`, gitignored — copy `includes/config.php.example` to `includes/config.php` and fill in your own credentials)
- `SQL file/` — schema dumps for local (`paintingPortal.sql`) and hosted (`paintingPortalSiteGround.sql`) deployment
- `Database-Setup_EasyPHP.docx` — local environment setup instructions
